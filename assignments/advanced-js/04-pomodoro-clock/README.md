# Pomodoro Clock

- **Course:** Advanced JS (9)
- **Lecture id:** 128
- **Status:** not started

## Task

A countdown timer built in JavaScript. The standard brief is a 25 minute work period followed by
a 5 minute break, with start/pause/reset controls.

## Planned structure

```
04-pomodoro-clock/
  index.html
  style.css
  timer.js
```

Plain JavaScript, no framework. The timer should keep correct time using timestamps rather than
counting `setInterval` ticks, so it does not drift when the tab is in the background.
